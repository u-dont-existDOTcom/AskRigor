## Goal

Integrate the owner-approved interview-evidence correction into AskRigor's
canonical reasoning and health protocols, project router, and patient-story
evidence contract without weakening current scientific gates, rewriting frozen
artifacts, or treating a selected anecdote as an independent frequency sample.

## Current overlap and defect

Universal already preserves evidence direction, specificity, target variables,
estimands, epistemic phase, source authority, and high-value questioning. HRP
already preserves patient-versus-episode counting, chronology, denominators,
solicitation mode, adverse-event ascertainment, deduplication, and limits on
population claims from anecdotes. The patient-story v0.1 contract also keeps
self-report distinct from causal proof and preserves privacy and consent.

The active layers do not explicitly preserve a generalized behavioral or symptom
recurrence report as its own evidence role. They do not distinguish a
conditionally sampled confirming example from an independent opportunity-level
observation, require exception-first recurrence calibration, or make the
expected information gain of an optional follow-up auditable. The v0.1
patient-story contract cannot encode the proposition, original quantifier,
denominator, context, exceptions, uncertainty, evidence role, sampling frame, or
follow-up rationale without flattening them into narrative fields.

## Implementation

1. Revise Universal to 20.5.22. Merge the lesson's compact reasoning-selection
   corrections into the existing selector, then add one nonduplicative canonical
   interview-evidence gate and a point-of-generation check.
2. Revise HRP to 20.5.26. Add a health-specific application for patient history,
   symptom recurrence, adverse effects, behavior/lifestyle reports, surveys,
   reviewer extraction, and evidence-gathering dialogue. Preserve existing
   episode, Dose-Regime, comparison, and forum gates.
3. Add a concise activation summary to `project/PROJECT_INSTRUCTIONS.md` so a
   fresh worker reaches the canonical gates at intake and follow-up time.
4. Preserve patient-story v0.1 unchanged. Add a versioned v0.2 evidence extension
   and matching JSON Schema that can attach typed recurrence, episode,
   counterexample, boundary, sampled-opportunity, trait, causal, and analyst
   evidence to a v0.1 story. Encode sampling and information-gain invariants.
5. Add a human-facing v0.2 interview/reviewer method. It will specify ordinary
   controls and exact export mappings and will prohibit human collection through
   raw JSON. No live/frozen collection is migrated because none exists in this
   repository.
6. Add a fail-closed migration script from the exact PR #198 protocol bytes,
   focused regression tests, current manifest/README receipts, and a concise
   audit/lesson record.
7. Preserve the compact Project router's stronger reasoning-selection rules and
   keep opportunity-sampling status separate from statistical independence.
