   byte-derived manifest/integrity behavior.

   behavior, verified by current tests.
7. The release, review, and privacy records below.
8. `../project/CODEX-CURRENT-STATE.md`: recovery checkpoint, not protocol or
   release authority.

`../README.md` is the repository entry point and command/source map. Manifests,
hashes, status records, release notes, plans, generated excerpts, and lesson
summaries are downstream receipts. None can replace, truncate, or amend either
complete XML protocol.
