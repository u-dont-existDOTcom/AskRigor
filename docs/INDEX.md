# AskRigor documentation index

## Authority

1. Current explicit owner correction.
2. `../protocols/HRP_Full.xml` and
   `../protocols/Universal_Instructions.xml`: complete canonical protocol bytes.
3. `../packages/protocol/src/index.ts` and `../tests/protocol.test.ts`:
   byte-derived manifest/integrity behavior.
4. `../project/PROJECT_INSTRUCTIONS.md`: research router and completion gate.
5. `../project/FORUM_SIGNAL_MODULE.md`: firsthand/forum evidence contract.
6. `../packages/contracts/`, `../packages/sources/`, and
   `../apps/research-mcp/`: source-access truth model, adapters, and public MCP
   behavior, verified by current tests.
7. The release, review, and privacy records below.
8. `../project/CODEX-CURRENT-STATE.md`: recovery checkpoint, not protocol or
   release authority.

`../README.md` is the repository entry point and command/source map. Manifests,
hashes, status records, release notes, plans, generated excerpts, and lesson
summaries are downstream receipts. None can replace, truncate, or amend either
complete XML protocol.
